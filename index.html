TRANSPARENCIA OPERATIVA

La escena se mueve.
Las evidencias se comprueban.

Los robots, sus gestos y los paquetes de información son una animación ilustrativa. Los resultados del panel proceden de comprobaciones HTTP registradas; no se generan a partir de la animación.

GitHub Actions ejecuta rondas ligeras cada hora y completas a las 09:00 y 21:00 de México. El informe semanal corresponde al lunes a las 09:00. GitHub puede retrasar ejecuciones. Los informes se registran aparte del código: ningún auditor hace commits ni despliega.

El agente Jefe valida al Gerente y te entrega el informe. Los robots no representan siete modelos de IA activos. Son siete responsabilidades con trabajos automáticos delimitados. Las cuentas de prueba, la telemetría privada y el lector de Discord siguen pendientes; no se declara activo el alcance completo 24/7.
